Review and upgrade the existing Vampire: The Masquerade app with the following goals:

PRIMARY GOAL
Turn the app into a clean, scalable, multilingual, edition-aware reference and play companion for Vampire: The Masquerade.

VERY IMPORTANT LANGUAGE REQUIREMENT
The app currently has a bug where some Spanish text still appears while English is selected. Fix this completely.

You must audit the entire app and ensure that:
- all visible UI text follows the currently selected language
- all content text follows the currently selected language
- no Spanish text appears when English is selected
- no English text appears when Spanish is selected
- no mixed-language screen is ever shown
- all buttons, labels, section titles, placeholders, tooltips, modals, error messages, loading states, empty states, breadcrumbs, tags, and cards are translated through the same language system
- if a translation is missing in the selected language, do NOT silently fall back to another language if that would create mixed-language output
- instead show a safe fallback like “Translation not available in this language yet” or hide that specific field until translated

STEP 1 — AUDIT THE CURRENT APP
Review all currently displayed information and components.
Find and fix all hardcoded strings.
Find and fix all cases where text is bypassing the translation system.
Find and fix all cases where data content is stored in one language only but rendered regardless of selected language.
Find and fix all places where navigation labels, card titles, or detail page labels are not properly localized.

STEP 2 — REFACTOR FOR A RELIABLE I18N SYSTEM
Implement a centralized localization system.

Requirements:
- create a single translation architecture used everywhere
- use translation keys for UI strings
- use structured per-language content for game data
- make all pages reactively update when language changes
- ensure no stale content remains mounted in the old language after switching
- ensure search placeholders, filters, tabs, and category labels also update with the selected language

Recommended structure:
- /locales/en.json
- /locales/es.json
- /locales/pt.json
- /locales/fr.json
- etc. for supported languages
- separate game content data from UI strings
- game content entries should use a translations object per language

Example content shape:
{
  "id": "brujah",
  "editions": ["V5", "V20"],
  "translations": {
    "en": {
      "name": "Brujah",
      "summary": "Passionate rebels and visionaries..."
    },
    "es": {
      "name": "Brujah",
      "summary": "Rebeldes apasionados y visionarios..."
    }
  }
}
